THIS IS SKIPPING ROPE TIME! — Y2K MINI EXHIBITION

HOW TO OPEN
1. Unzip the folder.
2. Open the folder in VS Code.
3. Right-click index.html > Open with Live Server (install the Live Server extension if needed).
   You can also double-click index.html to preview it in a browser.

FILES
index.html = website content
style.css = Y2K design and responsive layout
script.js = play/pause, sound, and video framing controls
assets/ = original motion video and poster mockups

VIDEO DISPLAY
The video starts in FILL mode (object-fit: cover) so there are NO empty side bars in the wide exhibition window. Since the original is vertical, the top and bottom are cropped in this mode. Click SHOW FULL FRAME to see the entire vertical composition (with side space).

QR CODE
Publish the website to a public URL first (for example GitHub Pages or Netlify), then generate a QR code for that URL. No fake QR code is included.

Poster mockups are digital mockups, not physical prints.
Google Fonts are optional; fallback fonts work offline.

Poster Gallery updated: 8 original poster designs (no street mockups).

UPDATED POSTER GALLERY: Uses the eight original full-resolution PNG uploads, not crops of a screenshot. The image CSS uses height:auto and object-fit:contain so the entire poster is visible.

Final section: two full-size, uncropped outdoor poster mockups (daylight and low-light).

Original motion reference GIFs added at the beginning of the exhibition: assets/original-motion-01.gif and assets/original-motion-02.gif.
